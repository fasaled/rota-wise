# Rota-Wise - Resumen Ejecutivo / Executive Summary

## Español

### ¿Qué es?
**Rota-Wise** es una aplicación web para crear horarios de trabajo justos y equilibrados para médicos.

### Problema que resuelve
Distribuir turnos médicos de manera equitativa considerando:
- Vacaciones
- Intervalos mínimos de descanso
- Fechas pre-asignadas
- Disponibilidad variable

### Características principales
✅ Algoritmo inteligente de programación  
✅ Calendario interactivo visual  
✅ Edición manual con validación  
✅ Tablas de resumen  
✅ Exportación a PDF/Word profesional  
✅ Guardado automático  
✅ Soporte multiidioma (EN/ES)  
✅ Temas claro/oscuro  

### Tecnología
- **Frontend**: Next.js 15 + React 18 + TypeScript
- **UI**: Tailwind CSS + Radix UI
- **Testing**: Jest (95%+ cobertura)
